# Dataset sources

Check licenses and usage terms before downloading.

- Crop recommendation: https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset
  Expected columns: N, P, K, temperature, humidity, ph, rainfall, label.
- Plant disease / PlantVillage: https://www.kaggle.com/datasets/emmarex/plantdisease
  Extract one folder per disease class under `datasets/plantvillage/`.
- Fertilizer prediction example: https://www.kaggle.com/datasets/atharvaingle/fertilizer-prediction
  Inspect labels and columns; local agronomic validation is essential.
- Crop yield: FAOSTAT https://www.fao.org/faostat/en/#data and India Open Government Data https://data.gov.in/
  Prepare a clean dataset with yield target and relevant regional variables.
- Weather: Open-Meteo https://open-meteo.com/ (public forecast endpoint; check terms and attribution).

Do not use randomly generated/demo data to claim real model performance.
